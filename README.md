
# Raios X - Ondas Eletromagnéticas

## Sobre o projeto

Este projeto apresenta informações sobre os Raios X, uma das principais ondas eletromagnéticas, abordando sua história, características e aplicações na tecnologia e na medicina.

## Conteúdo do site

- História dos Raios X
- Biografia de Wilhelm Conrad Röntgen
- Características das ondas eletromagnéticas
- Aplicações tecnológicas
- Aplicações na saúde e medicina

## Tecnologias utilizadas

- HTML
- CSS
